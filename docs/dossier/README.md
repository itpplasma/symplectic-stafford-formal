older conditional scaffolds and bounded pencil comparison. Its graph,
generated TeX, PDF and build manifest retain that historical scope. Claims in
those artifacts that the universal producer or local-length bridge is open
are superseded by the completed `SymplecticStafford/Paper/` development.

The maintained current correspondence is
[paper-lean-correspondence.md](../paper-lean-correspondence.md), with immutable
source pins and declaration cards in [paper-lean-map.json](../paper-lean-map.json).
The final human-readable paper is deferred. This historical dossier is not
that paper and is not the current Palomar submission description.
